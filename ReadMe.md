# 汉字小探险 用户手册

`汉字小探险` 是一个面向学龄前及小学低年级儿童的汉字学习桌面应用，采用分级学习、互动卡片和趣味游戏的方式，帮助孩子认识汉字、了解笔顺、练习拼读，并让家长查看学习情况。

## 适用对象

- 3-8 岁儿童
- 需要汉字启蒙或低年级识字练习的家庭
- 希望通过游戏化方式陪伴孩子学习的家长

## 主要功能

- `10` 个等级的分级识字内容
- 每级约 `80` 个汉字，整套共 `800` 字
- 汉字卡片学习
- 笔顺演示
- 拆字与字源小故事
- 练习游戏
- 多儿童档案
- 家长目标设置与学习统计
- 本地数据保存

## 功能页面说明

### 1. 首页

首页显示 `Level 1` 到 `Level 10` 的学习入口。

- 点击任意等级卡片可进入该等级的汉字列表
- 每张等级卡会显示等级名称、主题和字数

### 2. 学习页

学习页分为两个层级。

#### 汉字列表

- 以九宫格方式展示当前等级的汉字
- 每个汉字卡片会显示汉字和拼音
- 点击某个汉字进入详情页

#### 汉字详情卡片

详情卡片包含以下标签页：

- `概览`：查看拼音、声调、构字法、笔画数、部首、主题、组词和例句
- `笔顺`：播放汉字笔顺动画，逐笔查看书写过程
- `拆字`：查看汉字部件和结构信息
- `故事`：阅读字源、趣味说明和学习标签

### 3. 练习页

练习页提供 `5` 个小游戏。

- `字形拼图`：把部件拼成完整汉字
- `部首家族`：按偏旁部首归类
- `看图识画`：看图选字
- `描红工坊`：在屏幕上练习书写和描红
- `听音找字`：根据读音选择正确汉字

### 4. 我的

“我的”页面用于管理孩子档案。

- 添加新档案
- 选择头像
- 设置年龄段
- 切换当前学习档案
- 编辑档案名称和头像
- 删除档案
- 查看当前档案的学习统计和徽章

### 5. 家长面板

家长面板用于查看和调整孩子的学习目标。

- 查看今日学习时长
- 查看今日学习字数
- 查看今日游戏次数
- 设置每日学字目标
- 设置每日学习时长上限

如果当前还没有创建孩子档案，家长面板会提示先到“我的”页面创建或选择档案。

### 6. 设置

设置页可调整基本使用选项。

- 音效开关
- 字号大小
- 主题显示入口

## 安装与运行

### 环境要求

- Node.js `18+` 或更高版本
- npm
- Windows 桌面环境优先

### 首次安装

在项目根目录执行：

```bash
npm install
```

### 开发模式启动

```bash
npm run dev
```

启动后会：

- 启动 Vite 开发服务器
- 自动打开 Electron 桌面应用窗口

### 类型检查

```bash
npm run typecheck
```

### 生产构建

```bash
npm run build
```

说明：

- 构建会先打包前端，再打包 Electron 主进程
- 随后会调用 `electron-builder` 生成桌面应用安装包或发布产物
- 如果网络无法访问 Electron 下载源，打包阶段可能失败

## 基本使用流程

推荐第一次使用时按下面顺序体验：

1. 打开应用进入首页
2. 进入“我的”页面创建孩子档案
3. 返回首页选择一个 Level 开始学习
4. 点击汉字进入详情页，先看概览和故事
5. 切换到“笔顺”标签页观察书写顺序
6. 完成学习后进入“练习”页面做小游戏
7. 家长进入“家长面板”查看今日学习情况并设置目标

## 数据与保存

- 应用使用本地数据库保存档案和练习统计
- 当前学习数据默认保存在本机
- 更换电脑或清理本地数据后，历史记录不会自动同步

## 常见问题

### 1. 为什么家长面板没有数据？

可能原因：

- 还没有创建孩子档案
- 当前档案还没有产生学习记录

建议先到“我的”页面创建档案，然后进入学习页和练习页进行操作。

### 2. 为什么有些功能看起来还比较简单？

当前版本已经具备完整的学习流程，但部分统计、主题和打包资源仍可继续完善，属于后续可增强内容。

### 3. 为什么打包失败？

当前工程使用 `electron-builder` 打包。若出现失败，常见原因有：

- 网络无法访问 Electron 下载地址
- 本机缺少打包所需依赖环境
- 图标或发布配置未完整补齐

### 4. 笔画数和笔顺是否准确？

当前版本优先使用 `hanzi-writer` 提供的官方字符数据来展示笔顺和笔画数，因此展示结果会优先以官方笔顺数据为准。

## 温馨建议

- 家长可先从低等级开始陪孩子学习
- 每次学习不必太久，保持稳定节奏更重要
- 学完汉字后马上做小游戏，记忆会更牢
- 遇到多音字时，优先结合词语一起学习
